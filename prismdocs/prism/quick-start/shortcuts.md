**Prism** supports the following keyboard shortcuts.

## File

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New Project |
| `Ctrl+O` | Open |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As |
| `Alt+F4` | Exit |

## Edit

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+A` | Select all items in the focused list or canvas |
| `Ctrl+D` | Duplicate the selected item or items |
| `Ctrl+C` | Copy the selected item properties |
| `Ctrl+V` | Paste properties onto the selected item or items |
| `Delete` or `Backspace` | Delete the selected item or items |

On the [Regions](../stage/regions.md) page, `Ctrl+Shift+D` creates a sequential duplicate of the selected regions or DMX regions.

## View

| Shortcut | Action |
|----------|--------|
| `Ctrl+Left Arrow` | Back |
| `Ctrl+Right Arrow` | Forward |
| `Ctrl+Tab` | Next View |
| `Ctrl+Shift+Tab` | Previous View |
| `Ctrl+Up Arrow` | Collapse the selected list or cards |
| `Ctrl+Down Arrow` | Expand the selected list or cards |
| `F1` | Open Manual |

`Ctrl+Tab` and `Ctrl+Shift+Tab` cycle through the main views. `Ctrl+Left Arrow` and `Ctrl+Right Arrow` move through navigation history.

## Playback

| Shortcut | Action |
|----------|--------|
| `Space` | Play or pause |
| `Left Arrow` | Step backward on the timeline |
| `Right Arrow` | Step forward on the timeline |

The step size is set in [Playback Settings](../settings/settings-playback.md#playback).

On the [Regions](../stage/regions.md#canvas-controls) canvas, hold `Space` and drag to pan. `Ctrl+A` selects all regions.

## Numeric fields

| Shortcut | Action |
|----------|--------|
| `Up Arrow` / `Down Arrow` | Increase or decrease the value by the normal step |
| `Ctrl+Up Arrow` / `Ctrl+Down Arrow` | Increase or decrease the value by a finer step |
| `Enter` | Confirm the value |

## Dialogs

| Shortcut | Action |
|----------|--------|
| `Enter` | Confirm the active dialog, including delete confirmation, trim, and crop |
