**Prism Suite v2.2** adds new media types, DMX and pixel mapping, per-output geometry tools, and layer effects.

The sections below summarise the main **features** and **updates**. Each item links to the relevant page in this manual.

The full list of changes, including bug fixes, is in the [Prism Suite v2.2 Release Notes](https://web3.avolites.com/Portals/0/Downloads/ReleaseNotes/PrismSuite/Prism_Suite_v2_2_Release%20Notes.pdf).

## Features

- **[Layer effects](./play/layer-controls.md#effects)** - Apply layer effects, including 2D particle and shape generators.
- **[DMX outputs](./stage/outputs.md#dmx-output)** - Send DMX over sACN, Art-Net, or USB Expert.
- **[DMX regions and pixel mapping](./stage/regions.md#dmx-regions)** - Map surface or layer content to DMX fixtures.
- **[Edge blend and keystone](./stage/outputs.md#edge-blend)** - Apply edge blend and keystone on a physical output.
- **[MIDI Timecode (MTC)](./settings/settings-timecode.md#timecode-source)** - Use MIDI Timecode as a timecode source.
- **[Image sequences](./play/banks.md#image-sequence)** - Play a folder of sequential still images as a clip.
- **[Test pattern and gradient](./play/banks.md#test-pattern)** - Add generated test pattern and gradient bank elements.
- **[Duplicate surfaces](./stage/surfaces.md#surface-sub-menu)** - Duplicate a surface and its layers.
- **[HLS stream input](./play/banks.md#network-stream)** - Receive HLS network streams as well as RTSP.

## Updates

- **[USB Expert](./settings/settings-timecode.md#timecode-source)** - Updated USB Expert for LTC and MTC DMX.
- **[System Time](./settings/settings-timecode.md#timecode-source)** - Use the computer's system clock as a timecode source.
- **[ProRes and YUV](./play/banks.md#video)** - Improved support for ProRes profiles and YUV formats.
- **[Region tools](./stage/regions.md#canvas-controls)** - Zoom, pan, snap, multi-select, and create-region tools.
- **[Resizable pages](./play/play.md#layout-overview)** - The Play and Regions pages can be resized.
- **[Navigation highlighting](./quick-start/navigation.md#view-tabs)** - Clearer highlighting of the current view.
- **[Media Manager bank filter](./play/media-manager.md#filter-by)** - Filter media by bank.
- **[Copy and paste](./stage/outputs.md#edge-blend)** - Copy and paste edge blend, keystone, and DMX regions.
- **[UI rendering quality and preview](./settings/settings-general.md#graphics)** - Settings for UI rendering quality and previews.
- **[Delete confirmation](./settings/settings-general.md#application)** - Option to disable delete confirmation pop-ups.
- **[Automatic selection](./quick-start/navigation.md#multi-selection)** - Newly added or duplicated elements are selected automatically.
- **[Default lock status](./settings/settings-general.md#application)** - Default lock status for linked numeric fields.
- **[Output colour space](./stage/outputs.md#physical-output-controls)** - Colour space on output display settings.
- **[Numeric fields](./play/layers.md#controlling-the-layer)** - Finer control for speed and numeric text fields.
- **[Launch from start](./play/timecode-triggers.md#launch-from-start)** - Timecode triggers can launch media from the start of the clip.
- **[Synergy personality](./settings/settings-synergy.md)** - Updated Prism personality, including Sync to DMX and Reset to Default.
- **[Health check](./quick-start/system-tray.md)** - A health check runs when Prism starts.
- **[Live DMX channel data](./stage/outputs.md#live-dmx-channel-data)** - Live display of DMX channel values.
